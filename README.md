# ワナ見破り検定

実際の画面に近い再現を見て選ぶ、情報セキュリティのクイズです。登録なし・無料で、ブラウザだけで遊べます。

- **レベル1：まず知っておきたい15の手口**　ホモグラフURL、サブドメイン偽装、不在通知SMS、ニセ警察、偽CAPTCHA（ClickFix）、サポート詐欺 など
- **レベル2：本物そっくりを見抜く15問**　ブラウザ・イン・ザ・ブラウザ、中継型フィッシング（2段階認証の突破）、RLOによるファイル名偽装、返信メールの乗っ取り、ビジネスメール詐欺、プロンプトインジェクション など

## 安全のための作り

- サーバーを持たない静的サイトです。入力フォームも、外部への送信もありません。
- 回答や点数はどこにも送信しません。自己ベストだけを、遊んだ人のブラウザ（localStorage）に保存します。
- Content Security Policy で、読み込めるものを自分のファイルとGoogle Fontsだけに制限しています。外部のスクリプト・解析タグ・広告は使っていません。
- 問題に出てくる銀行・企業・アプリ名は架空です。再現画面のリンクはどこにも飛びません。コマンド例は実行できないよう改変しています。

## ファイル構成

```
index.html        画面の土台とセキュリティ設定
css/style.css     見た目
js/common.js      再現画面の部品と文字の分解表示
js/level1.js      レベル1の問題
js/level2.js      レベル2の問題
js/sources.js     各問の参照元リンクと該当箇所（hl はリンク先で強調する文。ページ本文と完全一致させる）
js/app.js         出題・採点・結果画面
```

問題を足すときは `js/level*.js` の `questions` に1問ずつ追加し、`js/sources.js` の同じ位置に参照元を足します。
